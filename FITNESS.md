# Fitness & Health Context

## Current Fitness Context

The user has experience preparing for and shooting a body profile, but does not
currently want to return to that level of strictness.

The current goal is a clear, athletic body condition that can be maintained in
real life.

Known metrics snapshot as of 2026-06:

- Height: 165 cm
- Recent weight: about 65 kg
- Recent body fat: about 19%
- Target weight: about 63 kg
- Target body fat: about 15%

Based on past InBody data and current body composition, the user considers
about 63 kg and 15% body fat to be a realistic target.

These numbers are useful as context, but should be refreshed when the user
provides newer body composition data.

## Current Goal

The goal is not simple weight loss. The actual goal is:

- Reduce body fat
- Maintain muscle
- Keep the result sustainable long term

The user prefers a realistic target over an idealized one. "Return to body
profile condition" is not the current goal. "Maintainable 15% body fat in real
life" is closer to the current target.

## Diet Philosophy

The user prefers realistic optimization over extreme cutting.

The user does not think in a "one meal ruined everything" frame. When eating
foods such as cookies, bagels, or zucchini pancakes, the user is more likely to
ask what actual effect the choice has on the overall trend.

Important lens:

- Overall flow
- Weekly change
- Long-term trend
- Body composition, not only scale weight
- Sustainability

## Tracking And Analysis Style

The user values weekly trend more than daily weight fluctuation.

Fitness and diet questions are often decision-validation questions. The user is
usually asking not only "did I lose weight?" but "was my approach correct?"

Common analysis topics:

- Weight trend
- Plateau causes
- Digestion or stool changes
- Whether a food choice was reasonable
- Whether the current strategy is still working

## Training Decision Style

The user does not usually ask "what is the best exercise?" in the abstract. The
more important question is "what is optimal for my current situation?"

The user's broader decision style appears in fitness as:

- Data-based tracking
- Cause analysis
- Understanding structure
- Long-term maintenance
- Realistic optimization under current constraints

Fitness is part of the user's broader life optimization system, not just a
short-term weight-loss project.

## Advice Style

Fitness guidance should be practical and sustainable.

When helping with diet or exercise decisions, consider:

- Goal
- Current constraints
- Sustainability
- Injury risk
- Tracking burden
- How the plan fits real life

Avoid guilt-based framing around individual meals. Prefer weekly trend,
decision quality, body composition, and long-term maintainability.

## Related Interests

The user's sports interests include wakeboarding, snowboarding, and solo action
sports where skill growth is visible over time.
