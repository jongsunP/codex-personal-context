# FE 업무 아이디어

처음에는 내부 개선·고객 기능·자동화·시각화까지 폭넓게 검토했습니다.
이후 고객과 회사에 **눈에 보이는 변화**를 주는 일에 무게를 두어, 배송·3D 캐러셀·공간/공정·주문 파일 데모를 만들었습니다.
이제 두 기준을 함께 보고 **먼저 해볼 과제**를 고르려 합니다.

## 우선 비교할 안건

- **실무 가치:** 자주 겪는 불편을 줄이는가, FE가 끝낼 수 있는가.
- **보여지는 성과:** 고객·동료에게 변화가 잘 보이는가, 서비스의 가치를 설명하기 좋은가.

| 순위 | 실무 가치 기준 | 보여지는 성과 기준 |
|---:|---|---|
| 1 | 파일 다운로드 실패 복구 | 글로벌 배송 현황·여정 탐색 |
| 2 | 내 업무 보기·연속 주문 탐색 | 기공소 공간·공정 시각화 |
| 3 | 주문 파일 모아보기 | 디자인 수정 전후 비교 |
| 4 | 앱 링크톡 첨부 실패 복구 | 3D 캐러셀·확대 개선 |
| 5 | 웹 E2E 업무 시나리오 보강 | 주문 파일 모아보기 |
| 6 | 화면·3D 성능 개선 | 내 업무 보기·연속 주문 탐색 |
| 7 | QA 제보 자동 수집 개선 | 화면·3D 성능 개선 |
| 8 | PR 자동 검증 강화 | 업로드 전 파일 점검 |
| 9 | 디자인 수정 전후 비교 | 파일 다운로드 실패 복구 |
| 10 | 업로드 전 파일 점검 | 앱 링크톡 첨부 실패 복구 |
| 11 | 디자인시스템·공용 UI 정비 | QA 제보 자동 수집 개선 |
| 12 | 3D 캐러셀·확대 개선 | 디자인시스템·공용 UI 정비 |
| 13 | 글로벌 배송 현황·여정 탐색 | 웹 E2E 업무 시나리오 보강 |
| 14 | 기공소 공간·공정 시각화 | PR 자동 검증 강화 |

**실무 쪽 추천은 실패 복구·내 업무 보기·주문 파일**, 시연 쪽 추천은 **배송·공간/공정**입니다. 배송·공정은 실제 데이터 연결을 확인해야 해서 실무 순위를 낮게 보았습니다.

코드·문서 조사를 바탕으로 한 Codex의 잠정 추천입니다. 실제 사용 빈도와 효과는 확인이 필요하며, 개발 순서는 아직 정하지 않았습니다. E2E는 이미 있는 실행 기반에 빠진 업무 검증을 보강하는 안건입니다.

- **[공간·공정](https://dentlink-experience-studio.parkjongsunfrankie.chatgpt.site/#lab)** — 공간에서 주문·담당·인계 확인. 팀 공간 데모·공유기공소 작업과 연결하되, 실제 공정 데이터와 동료 작업 범위를 확인해야 합니다.
- **[주문 파일](https://dentlink-experience-studio.parkjongsunfrankie.chatgpt.site/#files)** — 한 주문의 파일 검색·미리보기·다운로드. 열람 가능한 파일부터 시작하며, 전사 검색은 서버 지원을 확인해야 합니다.

## 처음 검토한 범위

위 추천 외에도 고를 수 있도록 원래 후보를 분류별로 남겼습니다.

- **내부 품질·개발 생산성**
  디자인시스템·구형 UI 정리 / UI 시각 회귀 검증 / PR 자동 검증 / 웹·앱 E2E / API 타입 정리·변경 감지 / 공용 패키지 의존성 / 다국어·시간대 / 화면 성능 / HTML·링크 표시 규칙
- **반복 업무·불편 개선**
  다운로드·앱 첨부 실패 복구 / 오류·재시도 통일 / 내 보기 저장 / 표 개인화 / 연속 주문 탐색 / 메뉴·최근 주문 찾기 / 채팅 초안 복원 / 개인 메시지 템플릿 / 주문 정보 복사·내보내기 / 접근성
- **주문·검토 기능**
  수정 전후 비교 / 여러 스캔 함께 보기 / 업로드 전 점검 / 주문 파일 탐색 / 치식·주문 옵션 연결 / 승인 자료 묶음 내보내기
- **데이터·공간 시각화**
  리메이크 원인 / 납기·작업량 히트맵 / 고객 피드백 / 배송 여정 / 미국 치과·거점 지도 / 기공소 작업 현황 / 공간 투어 / 운영 보고서(추가 구체화 중단)
- **운영 지원·자동화**
  QA 제보 개선 / 로그·분석 데이터 마스킹 / 릴리즈·화면별 오류 추적 / CS Copilot 근거 확인 / 개발·QA 상태 체험 / 영업·교육 데모

실시간 GPS·공정 병목 분석·전사 통합 분석·통합알림·팀 공용 저장·AI 임상 판정·실시간 공동 3D 검토는 별도 협업이 필요한 확장안입니다.
