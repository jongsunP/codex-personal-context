## 각 안건에서 하는 일 (실무 가치/보여지는 성과 순위)

* **파일 다운로드 실패 복구(1/9)** — 웹에서 여러 파일 중 일부만 다운로드에 실패했을 때, 실패한 파일을 표시하고 해당 파일만 다시 받을 수 있게 합니다.
* **내 업무 보기·연속 주문 탐색(2/6)** — ‘배송 중 주문’처럼 자주 쓰는 필터를 이름 붙여 저장하고, 목록의 조건·위치를 유지하면서 이전·다음 주문을 이어서 확인합니다. 개인 기기 저장부터 시작합니다.
* **주문 파일 모아보기(3/5)** — 한 주문에서 열람 가능한 원본·승인·수정 자료를 한곳에 모아 검색·미리보기·다운로드할 수 있게 합니다.
* **앱 링크톡 첨부 실패 복구(4/10)** — 첨부 전송 실패를 알리고 선택한 파일을 유지해, 파일을 다시 찾지 않고 재시도할 수 있도록 개선합니다.
* **웹 E2E 업무 시나리오 보강(5/13)** — 기존 웹 자동 테스트에 첨부 전송·재진입·실패 복구 등의 검증을 보강해, 업무가 끝까지 완료되는지 확인합니다.
* **화면·3D 성능 개선(6/7)** — 주문 목록과 3D 뷰어의 로딩·스크롤·회전 속도를 측정하고, 확인된 느린 구간을 개선합니다.
* **QA 제보 자동 수집 개선(7/11)** — 기존 제보 기능에 화면·버전 정보 자동 수집과 재현 단계·첨부 확인을 보강해, 문제 파악에 필요한 추가 질문을 줄입니다.
* **PR 자동 검증 강화(8/14)** — 코드 변경 범위에 필요한 타입 검사·린트·테스트를 자동으로 연결하고, 기존 검증에서 빠지는 부분을 보강합니다.
* **디자인 수정 전후 비교(9/3)** — 승인 이력의 두 자료를 골라 나란히 보며, 수정 요청이 어떻게 반영됐는지 사람이 직접 비교할 수 있게 합니다.
* **업로드 전 파일 점검(10/8)** — 파일을 보내기 전에 형식 오류·중복 같은 기술적 문제를 확인하고, 사용자에게 미리 안내합니다.
* **디자인시스템·공용 UI 정비(11/12)** — 구형·신형 버튼·입력창 등의 사용 기준을 정리하고, 자주 쓰는 화면부터 공통 기준에 맞춥니다.
* **3D 캐러셀·확대 개선(12/4)** — 여러 모델을 카드 목록에서 고르고 확대·회전·이전/다음 전환으로 확인하도록, 기존 뷰어의 탐색 경험을 개선합니다.
* **글로벌 배송 현황·여정 탐색(13/1)** — 지구본의 전체 배송 현황에서 지역·개별 배송으로 확대하며, 배송 상태와 이력을 연결해 보여줍니다.
* **기공소 공간·공정 시각화(14/2)** — 기공소의 층·구역에 주문 상태·담당·인계를 연결해, 어디서 어떤 작업이 진행되는지 살펴보게 합니다.

## 전체 리스트

### 내부 품질·개발 생산성

* 디자인시스템·공용 UI 정비
* UI 시각 회귀 검증 — 화면 변경 전후를 자동 비교
* PR 자동 검증 강화
* 웹 E2E 업무 시나리오 보강
* 앱 E2E 점검 — 기기에서 주문·채팅 흐름을 자동 검증
* API 타입 정리·변경 감지 — 서버 응답 형식이 바뀔 때 FE 영향 확인
* 공용 패키지 의존성 정리 — 공통 코드 사이의 불필요한 연결·순환 참조 정리
* 다국어·날짜·시간대 정비
* 화면·3D 성능 개선
* HTML·링크 표시 규칙 정리 — 본문 서식과 외부 링크 표시 방식 통일

### 반복 업무·불편 개선

* 파일 다운로드 실패 복구
* 앱 링크톡 첨부 실패 복구
* 오류·재시도 경험 통일
* 내 업무 보기 저장
* 표 열·순서·밀도 개인화 — 보이는 열과 순서·행 간격을 개인별로 설정
* 연속 주문 탐색
* 메뉴·최근 주문 빠른 찾기
* 채팅 초안 복원
* 개인 메시지 템플릿 — 반복 답변을 저장해 불러오기
* 주문 정보 복사·내보내기
* 핵심 화면 접근성 개선 — 키보드·스크린리더로도 업무를 처리하도록 개선

### 주문·검토 기능

* 디자인 수정 전후 비교
* 여러 스캔 함께 보기 — 파일별 표시·숨김·투명도를 조절하며 함께 확인
* 3D 캐러셀·확대 개선
* 업로드 전 파일 점검
* 주문 파일 모아보기
* 치식·주문 옵션 연결 — 치아를 선택하면 해당 보철·재료·옵션을 함께 표시
* 승인 자료 묶음 내보내기 — 캡처·주석·승인 자료를 한 묶음으로 출력

### 데이터·공간 시각화

* 리메이크 원인 분석 — 재제작 사유별 건수와 해당 주문 확인
* 납기·작업량 히트맵 — 날짜별 주문 집중도를 색으로 표시
* 고객 피드백 탐색 — 고객별 의견·사진·연결된 주문을 함께 확인
* 글로벌 배송 현황·여정 탐색
* 미국 치과·거점 지도 — 지도와 기관 목록·상세 정보를 연결
* 기공소 공간·공정 시각화
* 사무실·기공소 공간 투어 — 공간별 역할·장비·제작 과정을 소개
* 운영 보고서 생성 — 추가 구체화 중단

### 운영 지원·자동화

* QA 제보 자동 수집 개선
* 로그·분석 데이터 최소화·마스킹 — 수집 정보를 줄이고 민감한 내용을 가리기
* 릴리즈·화면별 오류 추적 — 어느 화면·버전에서 발생한 오류인지 확인
* CS Copilot 근거 확인 — 기존 CS 답변의 출처·원문 확인
* 개발·QA용 상태 체험 — 로딩·빈 화면·권한·오류 상태를 미리 재현
* 영업·교육용 체험 데모 — 가상 주문부터 검토·배송까지 체험

### 별도 협업이 필요한 확장안

* 실시간 배송 GPS·이동 경로
* 공정 체류 시간·병목·가동률 분석 — 대기 구간과 작업자별 처리 현황 분석
* 전사 고객·매출·피드백 통합 분석 — 여러 출처의 데이터를 연결해 전체 추세 확인
* 통합알림·예약 알림
* 팀 공용 보기·템플릿·기기 간 초안 동기화
* AI 스캔 품질·임상 적합성 판정
* 실시간 공동 3D 검토 — 여러 사람이 같은 모델·주석을 동시에 확인

## 우선 구체화한 4개 데모

‘보여지는 성과’를 중심으로 먼저 구체화한 4개 안건을 **가상 데이터로 체험하는 데모 앱**입니다.

* **[배송 탐색](https://dentlink-experience-studio.parkjongsunfrankie.chatgpt.site/#shipping)** — 지구본 → 지역 확대 → 개별 배송 이력. 실제 적용에는 기관·배송·좌표 연결 확인이 필요합니다.
* **[3D 캐러셀](https://dentlink-experience-studio.parkjongsunfrankie.chatgpt.site/#models)** — 모델 선택 → 확대·회전·전환. 기존 뷰어의 탐색 개선이며, 수정 전후 비교는 별도 후보입니다.
* **[공간·공정](https://dentlink-experience-studio.parkjongsunfrankie.chatgpt.site/#lab)** — 공간에서 주문·담당·인계 확인. 팀 공간 데모·공유기공소 작업과 연결하되, 실제 공정 데이터와 동료 작업 범위를 확인해야 합니다.
* **[주문 파일](https://dentlink-experience-studio.parkjongsunfrankie.chatgpt.site/#files)** — 한 주문의 파일 검색·미리보기·다운로드. 열람 가능한 파일부터 시작하며, 전사 검색은 서버 지원을 확인해야 합니다.
