# FE 업무 아이디어

처음에는 내부 개선·고객 기능·자동화·시각화까지 폭넓게 검토했습니다.
이후 고객과 회사에 **눈에 보이는 변화**를 주는 일에 무게를 두어, 배송·3D 캐러셀·공간/공정·주문 파일 데모를 만들었습니다.
이제 두 기준을 함께 보고 **먼저 해볼 과제**를 고르려 합니다.

## 우선 비교할 안건

- **실무 가치:** 자주 겪는 불편을 줄이는가, FE가 끝낼 수 있는가.
- **보여지는 성과:** 고객·동료에게 변화가 잘 보이는가, 서비스의 가치를 설명하기 좋은가.

### 각 안건에서 하는 일

아래 설명은 표의 **실무 가치 순서**입니다.

- **파일 다운로드 실패 복구:** 여러 파일 중 일부만 다운로드에 실패했을 때, 실패한 파일을 표시하고 해당 파일만 다시 받을 수 있게 합니다.
- **내 업무 보기·연속 주문 탐색:** ‘배송 중 주문’처럼 자주 쓰는 필터를 이름 붙여 저장하고, 목록의 조건·위치를 유지하면서 이전·다음 주문을 이어서 확인합니다. 개인 기기 저장부터 시작합니다.
- **주문 파일 모아보기:** 한 주문에서 열람 가능한 원본·승인·수정 자료를 한곳에 모아 검색·미리보기·다운로드할 수 있게 합니다.
- **앱 링크톡 첨부 실패 복구:** 첨부 전송 실패를 알리고 선택한 파일을 유지해, 파일을 다시 찾지 않고 재시도할 수 있도록 개선합니다.
- **웹 E2E 업무 시나리오 보강:** 기존 웹 자동 테스트에 첨부 전송·재진입·실패 복구 등의 검증을 보강해, 업무가 끝까지 완료되는지 확인합니다.
- **화면·3D 성능 개선:** 주문 목록과 3D 뷰어의 로딩·스크롤·회전 속도를 측정하고, 확인된 느린 구간을 개선합니다.
- **QA 제보 자동 수집 개선:** 기존 제보 기능에 화면·버전 정보 자동 수집과 재현 단계·첨부 확인을 보강해, 문제 파악에 필요한 추가 질문을 줄입니다.
- **PR 자동 검증 강화:** 코드 변경 범위에 필요한 타입 검사·린트·테스트를 자동으로 연결하고, 기존 검증에서 빠지는 부분을 보강합니다.
- **디자인 수정 전후 비교:** 승인 이력의 두 자료를 골라 나란히 보며, 수정 요청이 어떻게 반영됐는지 사람이 직접 비교할 수 있게 합니다.
- **업로드 전 파일 점검:** 파일을 보내기 전에 형식 오류·중복 같은 기술적 문제를 확인하고, 사용자에게 미리 안내합니다.
- **디자인시스템·공용 UI 정비:** 구형·신형 버튼·입력창 등의 사용 기준을 정리하고, 자주 쓰는 화면부터 공통 기준에 맞춥니다.
- **3D 캐러셀·확대 개선:** 여러 모델을 카드 목록에서 고르고 확대·회전·이전/다음 전환으로 확인하도록, 기존 뷰어의 탐색 경험을 개선합니다.
- **글로벌 배송 현황·여정 탐색:** 지구본의 전체 배송 현황에서 지역·개별 배송으로 확대하며, 배송 상태와 이력을 연결해 보여줍니다.
- **기공소 공간·공정 시각화:** 기공소의 층·구역에 주문 상태·담당·인계를 연결해, 어디서 어떤 작업이 진행되는지 살펴보게 합니다.

**실무 쪽 추천은 실패 복구·내 업무 보기·주문 파일**, 시연 쪽 추천은 **배송·공간/공정**입니다. 배송·공정은 실제 데이터 연결을 확인해야 해서 실무 순위를 낮게 보았습니다.

코드·문서 조사를 바탕으로 한 Codex의 잠정 추천입니다. 실제 사용 빈도와 효과는 확인이 필요하며, 개발 순서는 아직 정하지 않았습니다.

## 처음 검토한 범위

위 추천 외에도 고를 수 있도록 원래 후보를 분류별로 남겼습니다.

- **내부 품질·개발 생산성**
  디자인시스템·구형 UI 정리 / UI 시각 회귀 검증 / PR 자동 검증 / 웹·앱 E2E / API 타입 정리·변경 감지 / 공용 패키지 의존성 / 다국어·시간대 / 화면 성능 / HTML·링크 표시 규칙
- **반복 업무·불편 개선**
  다운로드·앱 첨부 실패 복구 / 오류·재시도 통일 / 내 보기 저장 / 표 개인화 / 연속 주문 탐색 / 메뉴·최근 주문 찾기 / 채팅 초안 복원 / 개인 메시지 템플릿 / 주문 정보 복사·내보내기 / 접근성
- **주문·검토 기능**
  수정 전후 비교 / 여러 스캔 함께 보기 / 업로드 전 점검 / 주문 파일 탐색 / 치식·주문 옵션 연결 / 승인 자료 묶음 내보내기
- **데이터·공간 시각화**
  리메이크 원인 / 납기·작업량 히트맵 / 고객 피드백 / 배송 여정 / 미국 치과·거점 지도 / 기공소 작업 현황 / 공간 투어 / 운영 보고서(추가 구체화 중단)
- **운영 지원·자동화**
  QA 제보 개선 / 로그·분석 데이터 마스킹 / 릴리즈·화면별 오류 추적 / CS Copilot 근거 확인 / 개발·QA 상태 체험 / 영업·교육 데모

실시간 GPS·공정 병목 분석·전사 통합 분석·통합알림·팀 공용 저장·AI 임상 판정·실시간 공동 3D 검토는 별도 협업이 필요한 확장안입니다.
