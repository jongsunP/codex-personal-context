# Project History Archive

These dated documents preserve earlier personal project checkpoints. Start
with the corresponding current file in `projects/`; read an archive only when
the exact earlier decision, revision, verification, or recovery history matters.

Words such as `current`, `pending`, `next`, and old action requests describe
the state at that time. They do not override newer instructions or authorize
implementation, Git changes, deployment, session cleanup, or resumed monitoring.

Archive headers identify the source and preservation method. Local absolute
paths and temporary evidence are historical pointers, not files restored by
pulling this repository. Preserve relative links when moving content.
